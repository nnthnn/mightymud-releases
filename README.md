# MightyMUD Releases

Public download archive for MightyMUD desktop builds. The application source is kept in a
private repository; this repository contains release notes and downloadable installers only.

## Download

Get the latest build from the [Releases](https://github.com/nnthnn/mightymud-releases/releases/latest)
page.

- **macOS** — `.dmg` for Apple Silicon and Intel
- **Windows** — `.exe` installer and `.msi` package
- **Linux** — `.AppImage`, `.deb`, and `.rpm`

MightyMUD is a native desktop client for Major MUD and other classic text worlds. You need access
to a compatible MUD server to play.

Release builds are published automatically from the private source repository. This repository is
for distribution only; it does not contain the application source.
